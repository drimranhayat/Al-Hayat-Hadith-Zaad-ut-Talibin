# مختار الطالبین — شرح زاد الطالبین

ڈاکٹر عمران حیات کی تدریسی پیشکش۔ اردو میں، دائیں سے بائیں، موبائل اور کمپیوٹر کے لیے تیار جامد تعلیمی ویب سائٹ۔

## مواد اور حدود

فراہم کردہ کتاب سے **۶۴ منتخب تدریسی اسباق** شامل ہیں؛ ۲۸۹ صفحات کی تمام روایات شامل نہیں۔ تشریح اور تدریسی سرگرمیاں نئے انداز میں مرتب کی گئی ہیں۔ طویل روایت کے منتخب حصے واضح نشان زد ہیں۔ ہر سبق میں کتاب کا صفحہ اور متعلقہ حصے کا اصل نمبر درج ہے۔ مزید تفصیل `SOURCES.md` اور `COVERAGE.md` میں ہے۔

- اعراب کے ساتھ عربی متن، اردو ترجمہ، تشریح اور عملی مثال
- ۴۴۶ لفظی اندراجات: عربی، اردو، English، نوعیت اور نحوی تجزیہ
- ہر سبق کے ۹ ٹیب: مطالعہ، الفاظ، تراکیب، نحو، قواعد، مشق، سوال جواب، کوئز، دہرائی
- ۵۱۲ مختصر سوال جواب اور ۳۸۴ وضاحت والے MCQs
- معنی ملانا، خالی جگہ، لفظی ترتیب، عملی صورت حال اور خود جانچ
- ہر سبق کا الگ رنگ، دن/رات تھیم، تلاش، محفوظ اسباق اور پیش رفت
- Amiri اور Jameel Noori Nastaleeq فونٹ مقامی فائلوں میں شامل

## کمپیوٹر پر چلائیں

اس ZIP کو کھول کر اس فولڈر میں چلائیں:

```sh
python3 -m http.server 8000
```

پھر `http://localhost:8000` کھولیں۔ کوئی npm، build یا سرور ڈیٹابیس درکار نہیں۔ پیش رفت صرف اسی براؤزر کے localStorage میں محفوظ ہوتی ہے؛ JSON export/import بھی دستیاب ہے۔

## GitHub Pages

1. فولڈر کے اندر کی تمام فائلیں اپنے GitHub repository کی root میں ڈالیں، `.github` سمیت۔
2. `main` برانچ استعمال کریں۔ دوسری برانچ کے لیے workflow کی branches ترتیب بدلیں۔
3. Settings → Pages → Source میں **GitHub Actions** منتخب کریں۔
4. شامل workflow کو push یا Actions میں دستی طور پر چلائیں۔

## مواد میں ترمیم

`data.js` میں اسباق، `rules.js` میں قواعد، `palette.js` میں رنگ، `style.css` میں ڈیزائن اور `app.js` میں تعامل ہے۔ `index.html` تمام مقامی assets لوڈ کرتا ہے۔ کوئی PDF یا اسکین ویب سائٹ میں شامل نہیں۔

```sh
node scripts/validate.cjs
```

یہ اسباق، ماخذ، ڈیٹا ساخت، سوالات، رنگ اور ضروری مقامی اثاثوں کی جانچ کرتا ہے۔ اشاعت سے پہلے عربی متن اور علمی تفصیلات کی اہل مدرس سے نظرثانی مفید ہے۔ یہ پیکیج فراہم کردہ کتاب کی نسبتیں درج کرتا ہے، ہر روایت کی مستقل تخریج یا صحت کی درجہ بندی نہیں کرتا۔
